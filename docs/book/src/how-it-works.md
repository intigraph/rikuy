# How it works

The portable legacy transport validates graph creation identity, bounded responses, row provenance and cursor order before rendering. Knowledge and Watches are disabled source candidates. The browser explorer is a read-only presentation over the bundled Quipu engine; operator pendants are excluded from the public source and build. Missing snapshots remain unavailable. Offline signing code is included disabled, without enrollment or private keys.

Portable source history is extracted independently of operator config and snapshots. The original sources and mapping are retained by the migration custodian; no production history is rewritten.

## Today and the retained client

The root opens `today/`, the consolidated Today source. It includes Needs you, Next, Pace, Board, Log, Explore and the stopped-owner view. The previous client remains under `legacy/`; Knowledge, Offline, enrollment and Deck keep their existing routes.

The public Today build has live readers disabled. Deployment owns `today/reader-config.mjs`, read-cost admissions and any operator snapshots; these are never imported from a running installation. With no admission the page renders unavailable evidence, rather than querying production. A cutover must preserve those deployment files and verify `source.json` plus Today and the legacy route through the trusted same origin. Source delivery does not authorize a cutover.

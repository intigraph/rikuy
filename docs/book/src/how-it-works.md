# How it works

The portable legacy transport validates graph creation identity, bounded responses, row provenance and cursor order before rendering. Knowledge and Watches are disabled source candidates. The browser explorer is a read-only presentation over the bundled Quipu engine; operator pendants are excluded from the public source and build. Missing snapshots remain unavailable. Offline signing code is included disabled, without enrollment or private keys.

Portable source history is extracted independently of operator config and snapshots. The original sources and mapping are retained by the migration custodian; no production history is rewritten.
